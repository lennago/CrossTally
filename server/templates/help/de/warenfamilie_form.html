Summe der Familie

Die Summe steht in der Leiteinheit. Jede Einheit geht, eine Familie in Litern kann lauter Flaschen in Stück halten. Innerhalb einer Dimension rechnet die Einheit selbst um (g ↔ kg, ml ↔ l). Eine Ware aus einer anderen Dimension bringt ihre eigene Umrechnung mit: dass eine Flasche 500 ml fasst oder eine Portion 120 g wiegt, steht auf der Seite der Ware. Fehlt sie dort, fragt das Formular beim Speichern danach und trägt den Faktor an der Ware ein.

Portionen

Neben den Einheiten der Waren steht immer die Portion zur Wahl. Keine Ware wird in Portionen geführt, aber eine Familie kann darin summieren: „Snacks“ zählt dann Riegel und lose Nüsse als Portionen. Jede Ware sagt dafür auf ihrer Seite, was eine Portion ist: „1 Portion = 1 Stk.“ oder „1 Portion = 100 g“. Fehlt die Angabe, fragt das Formular danach.

Gehört zu

Eine Familie kann unter einer anderen stehen. Ihre Waren werden dann auch dort mitgezählt, in der Einheit der Familie darüber. Summiert „Biere“ in Stück und „Flaschengetränke“ darüber in Litern, braucht jedes Bier seine Milliliter je Flasche. Was fehlt, fragt das Formular gesammelt ab.
