Wozu die Seite

Nicht jede Warenwirtschaft exportiert einen Bestand, und nicht jede Datei kennt jeden Artikel. Hier steht das Soll je Artikel zum Eintragen, in der Einheit, in der {{ inventur.haus.name }} ihn führt. Es gilt wie ein Soll aus der Datei: die Prüfliste zeigt die Differenz dazu, und beim Abschluss friert es mit ein.

Zwei Blöcke

Oben die Artikel ohne Soll: das ist die Arbeit. Darunter die mit Soll, ob aus der Datei oder von Hand. Ihre Felder sind gesperrt. Bearbeiten gibt genau diese Zeile frei, dann lässt sich der Wert ändern oder leeren. Leer heißt: das Soll wird entfernt. Was nicht freigegeben war, ändert „Speichern“ nicht, auch wenn im Browser etwas anderes gestanden hätte. Ohne JavaScript bleibt eine Zeile mit Soll gesperrt. Ein Soll darf auch negativ sein, so wie eine Warenwirtschaft einen Bestand ausweist, wenn mehr gebucht als geliefert wurde.

Datei und Hand

Ein Upload gilt ganz: er ersetzt auch, was von Hand eingetragen war, und die Meldung danach sagt, wie viele Werte das waren. Umgekehrt macht ein Wert von Hand aus einem Wert aus der Datei einen von Hand, denn jemand hat ihn gerade bestätigt oder ersetzt. Gepflegt wird nur in der Vorbereitung. Läuft die Zählung schon: „Zurück in die Vorbereitung“, die gezählten Mengen bleiben.
