Das Konto

Benutzername, Name, E-Mail-Adresse, Häuser, wann das Konto angelegt wurde und wann sich die Person zuletzt angemeldet hat, auf der Website oder in der Zähl-App.{% if mail_moeglich %} Was sich hier ändert, erfährt die Person per E-Mail.{% endif %}

Die Knöpfe

Bearbeiten öffnet das Formular für Benutzername, Name, Rolle, Häuser und Aktiv, für Administratoren auch die E-Mail-Adresse. Löschen entfernt das Konto. Am Konto hängen keine Zähldaten. Es verschwinden nur die Zuordnungen zu Häusern und Inventuren und die Passkeys. Wer den Betrieb verlässt, wird gelöscht, nicht auf inaktiv gesetzt.{% if mail_moeglich %} Einladung erneut senden steht bei einem Konto, das noch auf sein Passwort wartet: ein neuer Link, etwa wenn der alte abgelaufen ist.{% endif %}

Passwort und Adresse

Das Passwort ändert jede Person selbst, über das Kontomenü oben rechts, in der Zähl-App oder über die Sperrseite der Website. Die E-Mail-Adresse ebenso, oder ein Administrator ändert sie.{% if mail_moeglich %} Eine neue Adresse gilt erst, wenn die Person den Link aus der Mail bestätigt hat.{% endif %} Vergisst jemand sein Passwort, setzt ein Administrator in der Verwaltung ein neues.
