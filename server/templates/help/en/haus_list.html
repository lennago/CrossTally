Sites and locations

Every site carries its own articles. Below that it is divided into areas (“counter”, “store”) and locations (“counter front”, “freezer compartment”). Counting happens at the location, and the count list of the location sets the order in the counting app.

The numbers

  • Articles counts everything except “Not countable”. Next to it is the split into active, inactive and discontinued.
  • Active per inventory type is the workload: the active articles of each type. A type of which the site carries nothing active is missing there. An inventory of only that type cannot be created for the site either.
  • The number behind each location is the count of articles expected there.
