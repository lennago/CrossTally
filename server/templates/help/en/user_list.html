The list

Every account with role, sites and last sign-in, on the website or in the counting app. As long as the counting app stays signed in, the date does not change. Counters only use the counting app, managers this web interface too, administrators the administration on top. The column headers sort.

What the badges say

invited means: created without a password and never signed in.{% if mail_moeglich %} The person has not used the link from the e-mail yet.{% else %} Without a mail server no invitation goes out. An administrator sets a password in the administration and switches the account active.{% endif %} deactivated means: the account is signed out everywhere and cannot sign in, not in the counting app either, until someone activates it again.

Who changes whom

Managers create accounts and change counters and other managers. An administrator is changed or deleted only by an administrator. The e-mail address is changed by the person themselves or by an administrator. The password is changed by the person themselves. Whoever has forgotten theirs gets a new one set by an administrator in the administration.
