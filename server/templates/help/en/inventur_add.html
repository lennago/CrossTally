The types first

Counted are the articles of the chosen inventory types, and each becomes a tab in the counting app. No type counts another one along: an annual inventory is an inventory with all types, and “All” selects them in one go. Which types exist is set under Master data → Inventory types.

Then the sites

A site can be selected if it carries an active article of a chosen type. The others are greyed out, because their inventory would have nothing to count. If only one site carries cups, an inventory of the cups alone can only be created there. Together with the monthly inventory it works at every site. Where the cups are missing, their tab simply stays away.

One inventory per site

For every selected site an inventory of its own is created, with all chosen types. What connects them is the cut-off date. In the list they therefore stand together as one block. Whoever creates several sites lands afterwards in the run, which shows them side by side. A site has one inventory per day. If a type is missing there, it is added in preparation through “Change types”.

What happens on creation

  • The count lines of the active articles in the chosen types are created from the count lists of the locations: one per pack kept there, as long as it is active, plus one for weighing where the product is weighed, and exactly one per prepared item.
  • They arise when the inventory is created, later only in preparation: through “Change types” and when the target stock clarification brings an article back. If something turns up while counting, the counters create it in the counting app as an unexpected line.
  • As counters, whoever creates the inventory is entered, except for an administrator, who counts everywhere anyway. If the same people count everywhere, they can be set right here: with the box “Set the counters right here, for all chosen sites” the choice applies to every chosen site. Next to each name stand the person's sites. Without the box they are assigned afterwards on the page of each inventory, where the people assigned to the site are suggested. Only those assigned see the inventory in the counting app.
  • The inventory is then in preparation: time to import the target stock or to maintain it by hand. Counting only happens once it has been started explicitly.
