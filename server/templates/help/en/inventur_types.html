Changing the types

Which inventory types this inventory counts can be changed as long as it is in preparation. If a type was forgotten when creating, it is added here, without losing counters and target stock.

  • A new type gets its count lines from the count lists, as when creating.
  • With a deselected type its still empty lines drop out. Counted ones stay and come up at closing.

This only applies to {{ inventur.haus.name }}. The other sites of the day stay as they are. As when creating, the site needs an active article of one of the chosen types. If counting is already running, the counting apps hold their tabs. Then first “Back to preparation”.
