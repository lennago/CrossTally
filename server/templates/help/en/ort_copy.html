What happens when copying

{{ ort.name }} stays as it is. A second location is created beside it with the same count list: the same articles in the same order, with their packs, default quantities and the “Weighing” tick. A prepared item is left out if the site of the copy does not carry one of its ingredients, for instance because it has been discontinued since. After that both locations are independent. A change to one count list does not change the other.

Area and name

The copy can stand in any area, also in one of another site. The name only has to be free in that area. So in another area the copy may be called like the original.

Copying to another site

What the other site carries as well is taken over. An article that does not exist there is missing from the copy. The preview names it beforehand. To count it there, create it at the other site and then add it to the count list.

Counted quantities of a running inventory do not come along. The copy starts without a count.
